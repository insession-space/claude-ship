# session-dashboard

いまのセッションの状況を1つのペインにまとめて出す Claude Code の mod です。ペインには、要対応の項目、ship-session と受け入れ条件の進捗、現在のブランチの PR、このセッションで起動したサーバーとコンテナを並べます。あわせて、ほかのセッションのものまで止める一括停止の Bash 呼び出しを止めます。

## 入れる

```bash
claude plugin marketplace add insession-space/claude-ship
claude plugin install session-dashboard@claude-ship
```

Claude Code を再起動すると読み込まれます。mod は `hooks/hooks.json` の `modules` に書いたフックモジュール（`hooks/dashboard.tsx`）です。mods に対応していない Claude Code はこのモジュールを読まないので、何も起きません。PR の取得に `gh` を使うので、`gh auth login` を済ませておいてください。

## 開く・閉じる

`/dashboard` を打つとペインが開き、もう一度打つと閉じます。全画面表示ではトランスクリプトの横に、そうでないときは入力欄の上に出ます。

一度開くと、次のセッションの開始時に mod が自動で開き直します。自動で開くペインは、Claude Code の仕様で端末幅が 110 桁以上のときだけ描かれます。ペインの閉じるボタンや `/dashboard` で閉じると、次からは開き直しません。

## 何が出るか

上から次の4区画を縦に並べます。

```
╭ 要対応 3 ──────────────────────────────────────────────╮
│ ✖ CI 失敗  test (ubuntu-latest)                         │
│ ● 未解決のレビュースレッド 1 件                         │
│ ○ README に載っている                                   │
╰─────────────────────────────────────────────────────────╯
╭ Session ────────────────────────────────────────────────╮
│ ship-session  実装ループ · 2周目  到達点 PR まで        │
│ #33 ████████░░░░ 4/6  進捗を出す mod                    │
╰─────────────────────────────────────────────────────────╯
╭ PR ─────────────────────────────────────────────────────╮
│ #34 draft 作業中の Issue の受け入れ条件の進捗を出す…    │
│  ✔ 3   ✖ 1   ● 1   修正依頼 · 未解決 1                  │
│ 自分がレビュアーの open PR 2 件                         │
╰─────────────────────────────────────────────────────────╯
╭ 起動中 2 ───────────────────────────────────────────────╮
│ :5173   node              12分                          │
│ docker  app-db            12分                          │
╰─────────────────────────────────────────────────────────╯
```

要対応の区画には、CI の失敗したチェックの名前、未解決のレビュースレッドの数、まだ済んでいない受け入れ条件（最大3件）を出します。項目が無ければ、mod はこの区画を出しません。

Session の区画には、ship-session のフェーズ・レビューの周回・到達点と、acceptance-progress が表示している Issue の受け入れ条件の進捗を出します。どちらの値も無ければ、この区画も出しません。

PR の区画には、現在のブランチの PR の番号・draft・タイトル、CI の成功・失敗・実行中の数、レビューの判定、未解決のスレッド数を出します。CI の数は背景色つきのピルで描きます。最後の行は、あなたがレビュアーに指定されている open の PR の件数です。PR がマージ済みかクローズのときは状態だけを出し、CI とレビューの行と要対応は出しません。現在のブランチに PR が無いときは「PR なし」と出します。

起動中の区画には、セッション開始時点を基準に、あとから増えた待ち受けポート（`lsof -nP -iTCP -sTCP:LISTEN`）と docker コンテナ（`docker ps`）を経過時間つきで並べます。セッション開始前からあったものは出しません。

長いタイトルや項目は末尾を省略します。ドッキングしたペインの幅（約66桁）で行が崩れないようにしています。

## いつ読み直すか

| 対象 | 契機 |
| --- | --- |
| PR と CI | セッション開始時、`/dashboard` で開いたとき、`git push` か `gh pr` を含む Bash 呼び出しの後。CI のチェックが実行中のあいだだけ 60 秒ごと |
| 起動中のサーバーとコンテナ | Bash 呼び出しの後、30 秒ごと、`/dashboard` で開いたとき、ターンの終わり |
| Session の値 | ship-session と acceptance-progress が値を書き換えたとき（ペインを描くたびに読む） |

PR の取得は `gh pr view` が1回、未解決スレッドの GraphQL が1回、レビュー依頼の件数の検索が1回です。CI が実行中でないときは、定期的な取得をしません。

## 残っているサーバーとコンテナの知らせ

ターンの終わりに、このセッションで起動したサーバーやコンテナが残っていれば、mod がトーストで知らせます。同じ顔ぶれのあいだは繰り返しません。新しく増えたときにもう一度知らせます。

セッション終了時（`session.end`）のトーストも試しましたが、表示されませんでした。`/exit` で終えると端末が全画面表示から抜け、トーストを描く前に画面が消えます。そのため、知らせるのはターンの終わりだけにしています。

## 一括停止のガード

エージェントの Bash 呼び出しのうち、次の形を止めます。止めたときは、ポートや名前を指定した止め方の例を理由としてエージェントに返します。

| 止める形 | 理由に書く例 |
| --- | --- |
| `pkill -f ...` / `pkill --full ...` | `lsof -ti :5173 \| xargs kill`、`kill 12345` |
| `killall ...` | 同上 |
| `docker stop $(docker ps -q)` / `docker ps -q \| xargs docker stop`（`kill` / `rm` も） | `docker stop app-db`、`docker compose down` |

`kill <PID>`、`pkill vite`（`-f` なし）、`docker stop <名前>`、`--filter` で絞った `docker ps -q` は通します。ガードのフックが失敗したときは、呼び出しを止めずに通します。

## 前提にした判断

ship-session と acceptance-progress は、`plugin.json` の `dependencies` に書いていません。session-dashboard だけを入れても、ほかの2つは一緒に入りません。mod は2つの値を `$.state.get` で読み、相手が入っていないときや値が null のときは、その行を出しません。相手の型の契約（`PluginState`）は再宣言せず、`hooks/dashboard.tsx` の中で読む形だけを狭く書いて確かめています。

ship-session と acceptance-progress が入力欄の上に出すバンドは、そのまま残ります。ペインは `Box` と `Text` だけで組んでいるので、terminal とデスクトップアプリの Code タブの両方で描けます。

## 表示の言語

Claude Code の `language` 設定、直近のあなたの発話の言語、英語の順に決めます。

## 出さないもの

- PR のマージや CI の再実行など、ペインからの操作
- セッションをまたいだ台帳の保存
- 現在のブランチ以外の PR の詳細

## テスト

```bash
claude plugin validate plugins/session-dashboard
claude plugin test plugins/session-dashboard
```
