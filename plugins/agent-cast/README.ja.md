# agent-cast

子エージェント（Agent ツールで起動したサブエージェントとチームメイト）が走っている間、1体ずつキャラクターとして画面に出す Claude Code の mod です。何体がどの役割で動いていて、今どのツールを使っているかを、入力欄の上とスピナー行で確認できます。

## 入れる

```bash
claude plugin marketplace add insession-space/claude-ship
claude plugin install agent-cast@claude-ship
```

Claude Code を再起動すると読み込まれます。mod は `hooks/hooks.json` の `modules` に書いたフックモジュール（`hooks/cast-band.tsx`）です。mods に対応していない Claude Code はこのモジュールを読まないので、何も起きません。

## 何が出るか

### 入力欄の上のバンド

子エージェントが1体以上いる間、入力欄の上に1体1行で出します。

```
╭─────────────────────────────────────────────────────────╮
│ 子エージェント 3体                                      │
│ (o.o) Explore  認証まわりを探す          Read     12s   │
│ [-_-] Plan     実装方針を立てる          思考中    4s   │
│ (^_^) general-purpose 差分を読む         完了     31s   │
╰─────────────────────────────────────────────────────────╯
```

1行には、顔、エージェント種別、Agent ツールに渡された説明、今の状態、経過秒の順に並びます。

- 今の状態は、ツールを実行している間はそのツール名、それ以外は「思考中」です
- 終わったエージェントは「完了」になり、5秒後に行が消えます
- 終了の知らせが届かないままメインのターンが終わると、フォアグラウンドのエージェントを「中断」にして5秒後に消します。バックグラウンドのエージェントとチームメイトはメインのターンが終わっても走り続けるので、そのまま残します
- 6体以上いるときは5行まで出し、残りを「ほか N 体」の1行にまとめます
- 説明が長いときは、幅に合わせて末尾を省略します

ship-session の進捗バンドなど、他の mod も入力欄の上にバンドを出している場合は、両方を縦に並べて出します。

### スピナー行

子エージェントが走っている間、スピナー行の文言を、走っているエージェントの顔と体数に置き換えます。顔は5つまで並べ、超えた分は `+N` で出します。経過時間とトークン数はエンジンの表示のまま残ります。

```
✻ (o.o) [-_-] 2体が作業中… (12s · ↓ 2.1k tokens)
```

圧縮中などエンジンが自分の文言を出しているときは、そちらを優先して置き換えません。

## 顔の割り当て

顔はエージェント種別ごとに決まっています。

| 種別 | 顔 |
| --- | --- |
| `Explore` | `(o.o)` |
| `Plan` | `[-_-]` |
| `general-purpose` | `(^_^)` |
| `claude-code-guide` | `(?_?)` |
| `fork` | `(=_=)` |
| `teammate` | `(^o^)` |

プラグインのエージェントなど一覧にない種別には、種別名から計算した値で予備の顔を1つ選びます。同じ種別名なら常に同じ顔になります。同じ種別を並列で走らせたときは同じ顔が並ぶので、説明で見分けます。

## 表示の言語

Claude Code の `language` 設定、直近のあなたの発話の言語、英語の順に決めます。

## 出る場所

ターミナルとデスクトップアプリの Code タブに出ます。スピナー行はこの2つにしかないので、VS Code とモバイルではバンドだけが出ます。

## 出さないもの

- Workflow ツールが起動するエージェント（`agent.spawn` を通るかどうかを確かめていないため）
- キャラクターの差し替えや、操作で子エージェントを止める機能

## テスト

```bash
claude plugin validate plugins/agent-cast
claude plugin test plugins/agent-cast
```
