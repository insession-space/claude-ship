# secret-guard

シークレットの形をした文字列を、会話に記録される前に `[redacted:<種類>]` へ置き換える Claude Code の mod です。mod が伏せる場所は2つあります。1つはあなたの入力で、送信の前に伏せます。もう1つはモデルの返答で、保存と次のリクエストへの送り直しの前に伏せます。

Bash のコマンド文字列とステージ済みの diff を検査する command hook では、プロンプトに貼った文字列もモデルが返答に書いた文字列も検査できません。この mod はその2か所を受け持ちます。

## 入れる

```bash
claude plugin marketplace add insession-space/claude-ship
claude plugin install secret-guard@claude-ship
```

Claude Code を再起動すると読み込まれます。mod は `hooks/hooks.json` の `modules` に書いたフックモジュール（`hooks/guard.ts`）です。mods に対応していない Claude Code はこのモジュールを読まないので、何も起きません。

## 何をするか

### あなたの入力

あなたがプロンプトを送ると、mod はシークレットの形をした文字列を `[redacted:<種類>]` に置き換えてから、プロンプトをセッションに渡します。モデルにも、トランスクリプトのファイルにも、画面のユーザーメッセージにも、伏せたあとの文が届きます。続けて mod は、伏せた件数と種類をトーストで出します。

```
secret-guard: シークレットの形をした文字列を 1 件伏せてから送りました（google）。値のローテーションを検討してください。
```

トーストには値そのものを入れません。貼った値はクリップボードからすでに外へ出ているので、mod は値が漏れたものとしてローテーションを勧めます。

あなた以外から来たプロンプト（バックグラウンドタスクの通知、別のセッションからのメッセージ、スケジュールされたプロンプト）も同じように伏せます。

### モデルの返答

モデルの返答の行が保存される直前（`session.append` の door `response`）に、mod はその行の text ブロックを伏せます。メインの会話もサブエージェントの会話も対象です。thinking ブロックとツール呼び出しは、エンジンが元のまま戻すので触りません。返答を伏せたときはトーストを出しません。

## 検出する形

誤検知を抑えるため、既知の接頭辞を持つ形だけを探します。汎用の「高エントロピー文字列」は探しません。

| 種類 | 形 |
| --- | --- |
| `github` | `ghp_` / `gho_` / `ghu_` / `ghs_` / `ghr_` に英数字36文字以上が続くもの、`github_pat_` に70文字以上が続くもの |
| `anthropic` | `sk-ant-` に32文字以上が続くもの |
| `openai` | `sk-proj-` に32文字以上が続くもの。`sk-` に32文字以上が続き、大文字・小文字・数字をすべて含むもの |
| `google` | `AIza` にちょうど35文字が続くもの |
| `aws` | `AKIA` / `ASIA` に大文字と数字ちょうど16文字が続くもの |
| `slack` | `xoxa-` / `xoxb-` / `xoxp-` / `xoxr-` / `xoxs-` に数字と `-` と8文字以上が続くもの |
| `stripe` | `sk_live_` / `rk_live_` に英数字16文字以上が続くもの |
| `private-key` | `-----BEGIN ... PRIVATE KEY-----` から `-----END ... PRIVATE KEY-----` までの PEM ブロック。END の行より前で切れたブロックは、ヘッダ行とそれに続く base64 の行を伏せる |

直前に英数字がつながっている文字列は拾いません（`disk-...` は `sk-` のキーとして扱いません）。本文に16文字以上の base64 の並びが無い PEM ブロック（`...` で省略した説明用の例など）は伏せません。

## 制限

- **ストリーミング中に画面へ出た文字。** 画面はモデルの返答をストリーミングしながら描きます。mod が返答の行を書き換えるのは、ストリーミングが終わって行が保存されるときです。エンジンの `session.append` の説明には、画面・SDK のストリーム・Remote Control が書き換え前の行を表示しうると書かれています。そのため、ストリーミング中に画面へ出た文字をこの mod は伏せられません。その後にモデルが読む文と、トランスクリプトのファイルに残る文は、伏せたあとのものです。ストリームそのものを書き換える仕組み（`turn.step`）は別の仕組みなので、この mod には入れていません。
- **モデルが書くツール呼び出し。** モデルがツール呼び出しの引数（Bash のコマンド、書き込むファイルの中身など）に書いた値は伏せません。エンジンは返答の行の `tool_use` ブロックを元のまま戻すので、`session.append` のフックからは書き換えられません。書き換えられたとしても、ツールが実行する内容が変わってしまいます。
- **ツール結果は伏せません。** 理由は下の「伏せないもの」に書きました。
- **入力の履歴。** mod は `prompt.submit` でプロンプトを書き換えます。上矢印で呼び出す入力の履歴に、打ったままの文が残るかどうかは API の説明に書かれていません。履歴の扱いはこの mod に任せないでください。
- **表に無い形。** Google AI Studio で発行する Gemini の API キーは `AIza` の形なので伏せます。ほかのサービスのキー、パスワード、既知の接頭辞を持たないトークンは伏せません。

## 伏せないもの

- **ツール結果（door `tool-result`）。** mod はツール結果を伏せません。理由は次の3つです。
  - 画面はツール結果を、行の横に保存される構造化された記録（`toolUseResult`）から描きます。エンジンはこの記録を作られたまま保存します。行の文を伏せても、画面とトランスクリプトのファイルからは値が消えません。
  - モデルはファイルの中身の代わりに `[redacted:...]` を読むことになります。モデルがその文字列をファイルに書き戻したり、`Edit` の置き換え対象が見つからずに失敗したりして、エージェントの動きが変わります。
  - モデルがツール結果の値を返答に書き写した場合は、mod がその返答を伏せます。
- 外部サービスへのシークレットの送信、ファイルへの書き込み、キーのローテーションは扱いません。

## 失敗したとき

- 入力の検査に失敗したとき、mod はプロンプトを送らず、代わりに理由を表示します。もう一度送ってください。
- 返答を伏せる処理に失敗したとき、mod はその行の text ブロックをすべて `[redacted:secret-guard-error]` に置き換えます。検査していない文は保存しません。

## 表示の言語

Claude Code の `language` 設定、直近のあなたの発話の言語、英語の順に決めます。

## テスト

```bash
claude plugin validate plugins/secret-guard
claude plugin test plugins/secret-guard
```

テストの値はすべて偽物です。本物の接頭辞を持つ文字列は、実行時に2つに割った片側どうしを連結して組み立てます。ソースにキーの形をした文字列そのものは書いていません。
